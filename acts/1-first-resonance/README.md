# Act 1 · First Resonance

> The runite answers back. Resonate with each rune, one by one, and build a CLI app.

**Runes in this Act:** Aether, Whisper, Weaver, Chanter — then + Forger, Cipher, Keeper
**You build:** one CLI app — a small notes CRUD — that grows with every rune.
**You meet:** cast and spell in use, `.echoes` (first time), and the **artefact**. ([Act 0](../0-the-void/README.md) met the Grimoire; this Act meets the Artefact.)

In [Act 0](../0-the-void/README.md) you learned what a runite is. Now you use one. Every page adds one rune to the same app, so by the end you have a CLI app that adds, lists, edits and removes notes, remembers them, writes them to a file — and travels as one `.rune` file.

Start from the **Blank Starter** runite you made in [Install](../0-the-void/install.md). Run every command **inside the runite's folder**.
